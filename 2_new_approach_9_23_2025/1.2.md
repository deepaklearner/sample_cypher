### 📁 High-Level Project Structure

```
etl_project/
│
├── main.py                      # Entry point, orchestrates the ETL flow
│
├── config/
│   └── settings.py              # DB configs, batch sizes, constants
│
├── extract/
│   ├── __init__.py
│   ├── primary_extractor.py     # Extract logic for primary domains
│   └── non_primary_extractor.py # Extract logic for non-primary domains
│
├── transform/
│   ├── __init__.py
│   └── transformer.py           # Transformation logic for both types
│
├── load/
│   ├── __init__.py
│   └── neo4j_loader.py          # Handles load into Neo4j
│
├── utils/
│   ├── __init__.py
│   ├── logger.py                # Centralized logging
│   └── helpers.py               # Utilities like chunking, timers, etc.
│
└── logs/
    └── etl.log                  # (Optional) Logging output
```

---

### 🔄 Flow Controlled in `main.py`

The flow is strictly **sequential**:

1. **Extract + Transform + Load primary domains**

   * One domain at a time
2. **Extract + Transform + Load non-primary domains**

   * In small batches (e.g. 3200)
   * One batch at a time

This protects memory and keeps the system predictable.

---

### 🔁 Processing Logic (Abstracted)

#### Primary Domains Flow

* Get list of primary domains
* For each domain:

  * Extract → Transform → Load

#### Non-Primary Domains Flow

* Get list of non-primary domains
* Break into batches
* For each batch:

  * Extract → Transform → Load

### 🧱 Component Responsibility Summary

| Module/File                | Responsibility                            |
| -------------------------- | ----------------------------------------- |
| `main.py`                  | Orchestrate full ETL pipeline             |
| `settings.py`              | Central config (DBs, batch sizes, etc.)   |
| `primary_extractor.py`     | Fetch data for individual primary domains |
| `non_primary_extractor.py` | Fetch data for batches of non-primary     |
| `transformer.py`           | Clean, normalize, and prep data           |
| `neo4j_loader.py`          | Load transformed data into Neo4j          |
| `logger.py`                | Unified logging setup                     |
| `helpers.py`               | Batch chunking, timers, etc.              |
