## **3. Fetch Neo4j Data in Batches**

```cypher
MATCH (e:Entitlement)-[:HAS_OWNER]->(u:User)
WHERE e.entitlementName IN $batch_names AND e.targetSystem = $batch_target
RETURN e.entitlementName AS entitlementName, e.targetSystem AS targetSystem,
```

## **5. Batch Updates in Neo4j**

Use **`UNWIND`** in Cypher for batch relationship changes:

```cypher
// Add new owners
UNWIND $adds AS row
MATCH (e:Entitlement {entitlementName: row.entitlementName, targetSystem: row.targetSystem})
MATCH (u:User)
WHERE u.employeeNumber = row.owner OR u.aetnaresourceid = row.owner OR u.cvsnetworkid = row.owner
MERGE (e)-[:HAS_OWNER]->(u);

// Remove owners
UNWIND $removes AS row
MATCH (e:Entitlement {entitlementName: row.entitlementName, targetSystem: row.targetSystem})-[r:HAS_OWNER]->(u:User)
WHERE u.employeeNumber = row.owner OR u.aetnaresourceid = row.owner OR u.cvsnetworkid = row.owner
DELETE r;
```

* `$adds` and `$removes` are **lists of dicts** from Python: `{"entitlementName": ..., "targetSystem": ..., "owner": ...}`.
