Got it ✅ — you have **two data sources** (MySQL and Neo4j) containing entitlement records, and you want to:

1. Find **new rows** in MySQL (not present in Neo4j).
2. Find **modified rows** where any of `entitle_desc`, `risk_rating`, `priv`, or `resource_type` differ for the same `(entitle_name, entitle_source)` key.
3. Do this **efficiently** with **large datasets** using **pandas**.

Let’s go step-by-step and focus on **memory and speed optimization**.

---

### ⚙️ Step 1: Load the data efficiently

Make sure to load only needed columns and use efficient dtypes.

```python
import pandas as pd
import numpy as np
import pymysql
from neo4j import GraphDatabase

# Example: Fetching from MySQL
mysql_query = """
SELECT entitle_name as entitlementName, 
    entitle_source as targetSystem, entitle_desc as description, risk_rating as riskLevel, priv as privilegedAccess, 
    resource_type as entitlementType
FROM edwmaster.entitlement_master;
"""
mysql_df = pd.read_sql(mysql_query, mysql_connection)

# Example: Fetching from Neo4j
neo4j_query = """
MATCH (e:Entitlement)
RETURN e.entitle_name AS entitlementName,
       e.entitle_source AS targetSystem,
       e.entitle_desc AS description,
       e.risk_rating AS riskLevel,
       e.priv AS privilegedAccess,
       e.resource_type AS entitlementType
"""
neo4j_df = pd.DataFrame(neo4j_session.run(neo4j_query).data())
```

---

### ⚙️ Step 2: Optimize dtypes (saves memory)

Convert categorical-like columns to `category` and normalize text.

```python
# --- Step 1: Optimize datatypes ---
# Only low-cardinality columns are made 'category'
for col in ['targetSystem', 'privilegedAccess', 'entitlementType']:
    mysql_df[col] = mysql_df[col].astype('category')
    neo4j_df[col] = neo4j_df[col].astype('category')

# --- Step 2: Sort before merging (for speed) ---
mysql_df.sort_values(['entitlementName', 'targetSystem'], inplace=True)
neo4j_df.sort_values(['entitlementName', 'targetSystem'], inplace=True)
```

---

### ⚙️ Step 3: Use merge with indicator for comparison

This is **vectorized**, so it’s very fast.

```python
# --- Step 3: Merge efficiently on the unique key pair ---
merged = pd.merge(
    mysql_df,
    neo4j_df,
    on=['entitlementName', 'targetSystem'],
    how='left',
    suffixes=('_mysql', '_neo4j'),
    indicator=True,
    sort=False
)
```

---

### ⚙️ Step 4: Identify **new rows**

These exist in MySQL but not in Neo4j.

```python
# --- Step 4: Identify new rows (exist in MySQL but not Neo4j) ---
new_rows = merged.loc[merged['_merge'] == 'left_only', [
    'entitlementName', 'targetSystem',
    'description_mysql', 'riskLevel_mysql',
    'privilegedAccess_mysql', 'entitlementType_mysql'
]]
```

---

### ⚙️ Step 5: Identify **modified rows**

Compare columns row-wise efficiently using vectorized operations.

```python
# --- Step 5: Identify modified rows ---
common = merged.loc[merged['_merge'] == 'both'].copy()

changed_mask = (
    (common['description_mysql'] != common['description_neo4j']) |
    (common['riskLevel_mysql'] != common['riskLevel_neo4j']) |
    (common['privilegedAccess_mysql'] != common['privilegedAccess_neo4j']) |
    (common['entitlementType_mysql'] != common['entitlementType_neo4j'])
)

modified_rows = common.loc[changed_mask, [
    'entitlementName', 'targetSystem',
    'description_mysql', 'description_neo4j',
    'riskLevel_mysql', 'riskLevel_neo4j',
    'privilegedAccess_mysql', 'privilegedAccess_neo4j',
    'entitlementType_mysql', 'entitlementType_neo4j'
]]
```

### ⚙️ Step 6: (Optional) Further optimization for very large data

If datasets are huge (millions of rows):

* ✅ Ensure both are **sorted by key** (`entitle_name`, `entitle_source`) before merging — speeds up the merge.
* ✅ Use `merge(..., sort=False)` to prevent sorting overhead.
* ✅ If data is too large for memory:

  * Use **chunked processing**: read MySQL/Neo4j data in batches.
  * Or use **Dask DataFrame** (drop-in replacement for pandas).

Example with sorting optimization:

```python
mysql_df.sort_values(['entitle_name', 'entitle_source'], inplace=True)
neo4j_df.sort_values(['entitle_name', 'entitle_source'], inplace=True)

merged = pd.merge(
    mysql_df, neo4j_df,
    on=['entitle_name', 'entitle_source'],
    how='left',
    suffixes=('_mysql', '_neo4j'),
    indicator=True,
    sort=False
)
```
