## 🧾 **1. Data Shape Assumptions**

### A. `neo4j_data`:

Result of Neo4j query:

```cypher
UNWIND $entitlements AS ent
MATCH (e:Entitlement {
  entitlementName: ent.entitlementName,  
  targetSystem: ent.targetSystem
})
OPTIONAL MATCH (e)-[:HAS_OWNER]->(u:User)
RETURN
  e.entitlementName AS entitlementName,
  e.targetSystem AS targetSystem,
  collect({
    employeeNumber: u.employeeNumber,
    isActive: CASE WHEN u:Active THEN true ELSE false END
  }) AS owners
```

Returned as a Python dict like:

```python
neo4j_data = {
  ("Entitlement1", "SystemA"): [
    {"employeeNumber": "E001", "isActive": True},
    {"employeeNumber": "E002", "isActive": False}
  ],
  # more entitlements...
}
```

## 🧠 **2. Delta Computation Function**

```python
def compute_deltas(current_edw, neo4j_data):
    results = []

    all_keys = set(current_edw.keys()) | set(neo4j_data.keys())

    for key in all_keys:
        entitlement_name, target_system = key
        edw_owners = set(current_edw.get(key, []))
        neo4j_owners_info = neo4j_data.get(key, [])

        active_neo4j = set(u['employeeNumber'] for u in neo4j_owners_info if u['isActive'])
        inactive_neo4j = set(u['employeeNumber'] for u in neo4j_owners_info if not u['isActive'])
        all_neo4j = active_neo4j | inactive_neo4j

        missing = edw_owners - all_neo4j
        inactive = edw_owners & inactive_neo4j
        matched = edw_owners & active_neo4j
        removed = all_neo4j - edw_owners  # Final definition

        results.append({
            "entitlementName": entitlement_name,
            "targetSystem": target_system,
            "missing": list(missing),
            "inactive": list(inactive),
            "matched": list(matched),
            "removed": list(removed)
        })

    return results
```

## 🔁 **3. Cypher Update Template**

Use this to apply the delta in Neo4j:

```cypher
UNWIND $records AS row

// Match entitlement
MATCH (e:Entitlement {
  entitlementName: row.entitlementName,
  targetSystem: row.targetSystem
})

// Step 1: Remove REMOVED owners (no longer in EDW)
UNWIND row.removed AS removedOwner
MATCH (e)-[r:HAS_OWNER]->(u:User {employeeNumber: removedOwner})
DELETE r
MERGE (e)-[:REMOVED_OWNER]->(u)

WITH e, row

// Step 2: Remove INACTIVE owners (present in EDW but user not active)
UNWIND row.inactive AS inactiveOwner
MATCH (e)-[r:HAS_OWNER]->(u:User {employeeNumber: inactiveOwner})
WHERE NOT u:Active
DELETE r
MERGE (e)-[:PREVIOUS]->(u)

WITH e, row

// Step 3: Add MISSING owners (new in EDW)
UNWIND row.missing AS newOwner
MATCH (u:User {employeeNumber: newOwner})
MERGE (e)-[:HAS_OWNER]->(u)
```
