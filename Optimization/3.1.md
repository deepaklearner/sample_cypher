### **Step 1: Fetch Data**

Assuming you have already fetched data:

```python
import pandas as pd
from sqlalchemy import create_engine
from neo4j import GraphDatabase

# MySQL connection
engine = create_engine("mysql+pymysql://user:password@host/dbname")
mysql_query = "SELECT entitlementName, targetSystem, owner1, owner2, owner3 FROM edw_table"
df_mysql = pd.read_sql(mysql_query, engine)

# Neo4j connection
uri = "bolt://neo4j_host:7687"
driver = GraphDatabase.driver(uri, auth=("neo4j_user", "password"))

def fetch_neo4j_data(tx):
    query = """
    MATCH (e:Entitlement)
    RETURN e.entitlementName AS entitlementName, e.targetSystem AS targetSystem,
           e.owner1 AS owner1, e.owner2 AS owner2, e.owner3 AS owner3
    """
    return pd.DataFrame([dict(record) for record in tx.run(query)])

with driver.session() as session:
    df_neo4j = session.read_transaction(fetch_neo4j_data)
```

---

### **Step 2: Reshape Data**

To make comparisons easier and faster, **unpivot the owner columns into long format**. This is key for optimized comparison.

```python
owner_cols = ["owner1", "owner2", "owner3"]

# Convert MySQL to long format
df_mysql_long = df_mysql.melt(
    id_vars=["entitlementName", "targetSystem"],
    value_vars=owner_cols,
    value_name="owner"
).dropna(subset=["owner"])

# Convert Neo4j to long format
df_neo4j_long = df_neo4j.melt(
    id_vars=["entitlementName", "targetSystem"],
    value_vars=owner_cols,
    value_name="owner"
).dropna(subset=["owner"])
```

Now each row is `(targetSystem, entitlementName, owner)` — easy to compare.

---

### **Step 3: Compare Owners**

Use **set operations** via `merge` and `indicator=True` to find new and removed owners:

```python
# Owners in MySQL but not in Neo4j → New owners
df_new_owners = df_mysql_long.merge(
    df_neo4j_long,
    on=["targetSystem", "entitlementName", "owner"],
    how="left",
    indicator=True
).query('_merge == "left_only"').drop(columns="_merge")

# Owners in Neo4j but not in MySQL → Removed owners
df_removed_owners = df_neo4j_long.merge(
    df_mysql_long,
    on=["targetSystem", "entitlementName", "owner"],
    how="left",
    indicator=True
).query('_merge == "left_only"').drop(columns="_merge")
```

✅ These operations are **vectorized** in pandas and scale much better than row-by-row loops.

### **Step 4: Update Neo4j**

You can batch updates to Neo4j for efficiency:

```python
def update_owners(tx, target_system, entitlement, owner, action):
    if action == "add":
        query = """
        MATCH (e:Entitlement {entitlementName:$entitlementName, targetSystem:$targetSystem})
        SET e.owner1 = coalesce(e.owner1, $owner)
        """
    else:  # remove
        query = """
        MATCH (e:Entitlement {entitlementName:$entitlementName, targetSystem:$targetSystem})
        WITH e, [$owner] AS remove_owner
        UNWIND keys(e) AS k
        WITH e, k, remove_owner
        WHERE e[k] IN remove_owner
        REMOVE e[k]
        """
    tx.run(query, entitlementName=entitlement, targetSystem=target_system, owner=owner)

with driver.session() as session:
    for _, row in df_new_owners.iterrows():
        session.write_transaction(update_owners, row.targetSystem, row.entitlementName, row.owner, "add")
    for _, row in df_removed_owners.iterrows():
        session.write_transaction(update_owners, row.targetSystem, row.entitlementName, row.owner, "remove")
```

### **Step 5: Report Missing Owners / Inactive**

For reporting:

```python
# Missing in Neo4j (entitlement not present)
missing_entitlements = df_mysql_long.merge(
    df_neo4j_long,
    on=["targetSystem", "entitlementName"],
    how="left",
    indicator=True
).query('_merge == "left_only"')[["targetSystem", "entitlementName", "owner"]]

# Owners in Neo4j but inactive in MySQL
inactive_owners = df_removed_owners.copy()

# Save reports
missing_entitlements.to_csv("missing_entitlements.csv", index=False)
inactive_owners.to_csv("inactive_owners.csv", index=False)
```

---

### **Optimization Notes**

1. **Use long format** (`melt`) to avoid complex nested loops.
2. **Vectorized `merge` + `indicator`** is much faster than `apply` or iterating row by row.
3. **Batch updates** in Neo4j using transactions; don’t write one by one if possible — you can even `UNWIND` a whole list of owners.
4. **Avoid loops in pandas** for large datasets; always prefer `merge`, `concat`, `groupby`, and `melt`.
